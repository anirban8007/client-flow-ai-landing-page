# ClientFlow AI — Landing Page

A modern, responsive landing page for **ClientFlow AI**, an AI-powered business assistant that automates client communication, manages projects, generates invoices, and streamlines workflows.

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React

## ✨ Features

- Hero section with AI chat demo mockup
- Features & Benefits showcase
- How It Works section
- Pricing plans
- Testimonials
- Integrations section
- FAQ accordion
- CTA & Footer
- Fully responsive (mobile + desktop)
- Dark mode support

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/anirban8007/client-flow-ai-landing-page.git

# Navigate into the project
cd client-flow-ai-landing-page

# Install dependencies
npm install

# Run the development server
npm run dev
